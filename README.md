# so_long

So Long is a small 2D game project made as part of the 42 curriculum. The goal is to create a simple maze game using the MLX42 graphics library.

The player must collect all the items on the map and reach the exit. The map is read from a .ber file and validated according to specific rules.

This project was a great opportunity to learn about:

    Basic 2D graphics rendering

    Event handling (keyboard input)

    Game loop design

    Memory management in C
